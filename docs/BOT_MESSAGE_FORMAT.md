# Bot Message Format

Standar format output bot:

- Template: `[Fitur] — Pesan singkat. (Detail opsional)`
- Contoh reward: `[RPG] — Reward dari misi 'Goblin Raid': 50 gold diberikan.`
- Untuk user premium, label harus ditulis tebal: `**Premium**`.

Format ini dipakai untuk konsumsi downstream (UI/chat log parser) agar konsisten.
